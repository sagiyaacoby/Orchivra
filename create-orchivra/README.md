# Orchivra

Create a local AI agent team with a dashboard, tracked tasks, persistent memory, and Claude CLI integration.

```sh
npx create-orchivra my-team
cd my-team
```

Launch with `launch.bat` on Windows or `bash launch.sh` on macOS and Linux, then open the dashboard address printed by the server.

Requires Node.js 18 or later. Install Claude CLI separately to use the Command Center.
